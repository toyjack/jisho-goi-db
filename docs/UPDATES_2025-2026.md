- **Tsj-Wakun（新撰字鏡・和訓）**: Supabase（PostgreSQL）を利用した新規モジュールとして追加。検索フォーム・結果ページ・詳細ページ・レイアウトを実装。
- **Racvyoxv**: Supabase 連携による検索フォームと結果ページを新規追加。マニフェスト処理やデータ取得ロジックを含む詳細ページも整備し、追加の検索パラメータに対応。
- Supabase 型定義（`lib/supabase/types.ts`）の生成方法を整理し、`prisma/schema.prisma` のプロバイダを PostgreSQL に更新（Row Level Security 対応のモデル修正込み）。
- ユーザーロール・型ハンドリングを各コンポーネントで見直し。

## 3. Tsj-Wakun を外部API（hdicviewer-rebuild）へ移行

今期最大の作業。Supabase への直接クエリから、外部の hdicviewer-rebuild 公開API（本番: `https://hdic-app.kojisho.com`、全20,017件収録）へ全面移行。

- 検索結果の関連性バグを修正: `matchedPartIds` に頼ったフォールバックが多発し、無関係な行（例: 「乱」検索で「攪乱」など無関係な注釈にヒット）が大量に混入していた問題を、実際に検索対象フィールドと照合するロジックに変更して解消。
- variant_search（異体字検索）トグル、entryType / posCategory / charCount / kanaCount の絞り込みフィルタを追加。
- ひらがな検索でヒット数が0件になるバグを修正（`readingKanaKanji` は片仮名格納のため、平仮名への正規化をAPI側・クライアント側の両方で追加）。
- 和訓データを持たない見出し語（例:「先」）が結果から黙って除外されていた問題を修正し、「和訓なし」と明示表示するように変更。
- JapanKnowledge へのリンクURL形式の誤りを修正（`/psnl/{id}` → `/psnl/display/?lid={id}`）。
- サイト共通のリンク色（`link-primary` は配色上ほぼ読めない）を `link-hover` に統一。
- 検索パネルのフィールドラベル・品詞/種別セレクトの選択肢を実際の会議内容に合わせて修正。
